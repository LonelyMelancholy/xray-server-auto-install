**INBOUNDS**

***Протоколы и транспорты***

По умолчанию настроенный 'inbound' работает только с 'vless tcp reality'. Скрипты совместимы только с одним настроеным 'inbound tag=Vless'. Юзеры всегда добавляются с 'flow=xtls-rprx-vision'. Порты и какие то мелочи можно менять вручную, но следует учитывать что другие протоколы я не добавлял, поэтому пользователь добавляется и ссылка для подключения генерируется с учетом только 'tcp reality', на данный момент не вижу смысла добавлять другие транспорты, они не спасают от блокировок по подсетям и детектируются точно так же. Трафик на любых портах кроме 443 так же очень подозрителен, по этому использование нескольких 'inbound' бессмысленно. Может потом добавлю 'xhttp' но только если будет решена проблема с использованием оперативной памяти на айфонах и будет реальная необходимость в этом.

***Блокировки и маршрутизация***

По умолчанию во всех конфигурациях заблокирован трафик к "geoip:private", "geoip:ru", нескольким зарубежным доменам для определения ип, а так же "bittorrent". Если вам это не нужно просто отредактируйте вручную.

***Мост с двумя серверами***

Всех пользователей добавляем на первую ноду, фильтрации нет, все уходит в outbound на второй сервер, там осуществляем блокировку и маршрутизацию, так сделано для того что бы мы могли подключатся в случае чего на второй сервер и не ломать маршрутизацию. Пример тестового конфига входной ноды лежит в 'in_node.json', для установки просто заменить 'config.json' перед установкой, затем заменить 'direct outbound' на 'outbound' из 'in-node-outbound.json', выходная работает на стандартном конфиге.
