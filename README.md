# xray-server-auto-install
По всем вопросам телеграмм [@lonely_melancholy](https://t.me/lonely_melancholy)

### О проекте.
Данный проект в целом задумывался для того что бы быть полностью независимым от того предоставляет ли хостер предустановленные образы или нет и как отход от привычных панелей управления как от перегруженных костыльных решениях, в частности мне не нравится мониторинг у того же 3x-ui где для просмотра информации о сервере я должен либо тыкать миллион кнопок в боте либо логинится в панель, потребление ресурсов так же не соответствует функционалу панели, Remnawave имеет более широкий функционал но запредельные системные требования. Разбиратся в куче видов этих панелей и пытатся закастомить их под себя не было никакого желания, а так же мне надоело настраивать кучу софта при установке, и обновлять все это руками. Тогда и было начато создание этого скрипта. Он предназначен для автоматической установки и полной настройки сервера для личного использования, с наличием всего нужного функционала для администрирования. В конечном результате вы получаете сервер:
1. С минимально возможным потреблением ресурсов, чистый Xray-core.
2. Полное управление через телеграмм бота или по ssh через скрипты в домашней директории. Весь функционал управления реализован через bash скрипты.
3. Без лишних открытых портов и лишнего установленного софта, наружу будет торчать только ssh, nginx и xray, nftables настроен на дроп всего входящего кроме этих портов.
4. SSH доступом настроенным на безопасность уровня параноик и доступом по ключу.
5. Включенный fail2ban для исключений попыток брутфорса SSH. Банит по всем протоколам и портам на 30 дней.
6. Автоматические обновления geo баз, xray, безопастности системы и авто перезагрузкой при необходимости, автобан юзеров по истечению их времени, нормы трафика, сбор статистики трафика год/месяц, авторазбан по трафику при сбросе трафика в начале месяца.
7. Уведомления в Телеграмм бота о включении сервера, логине по ssh и разлогине, уведомление о потраченном трафике за месяц и о автобанах тех у кого исчерпан лимит, уведомление о оставшемся времени у юзеров и о автобанах тех у кого оно истекло, уведомление о обновлении и перезагрузке сервера, уведомление о обновлении xray, уведомления о обнаруженных и забаненых за брутфорс ip адресах и их разбане.


### Обязательные требования:
- Свежая установка для избежания конфликтов конфигураций Ubuntu 24.04 и новее.
- Подготовленный в конфигурационном файле - новое доменное имя сервера (домен 2 или 3 уровня обязателен для selfsteal), новый пароль рута и администратора сервера, token телеграмм бота, chat id юзера для работы с ботом, group id группы для уведомлений, email для настройки сертификатов сервера, одно имя пользователя для генерации конфигурации впн, количество дней которые действует это имя пользователя (0 - бесконечно).

### Необязательные требования:
- Ключ Ubuntu pro

### Установка:
- Скачайте скрипт в любую директорию `git clone https://github.com/LonelyMelancholy/xray-server-auto-install.git`
- Заполните конфигурационный файл для автоустановки `configuration.cfg`
- Предполагается что вы работаете от root, если нет используйте полноценную сессию через `sudo -i`
- Запустите `./pred-install.sh`, скрипт проверит правильность заполнения, обновит и перезагрузит систему
- Запустите `./install.sh` установит все необходимые программы и настройки
- Скопируйте приватный ключ который в конце установки выдаст скрипт и порт подключения, настройте ssh клиент для работы с ним, если у вас несколько ключей для разных серверов ssh-agent использовать нельзя, он перебирает ключи по очереди при подключении и после 3 неправильного ключа вас забанит.

### Управление сервером и xray:
- Полное управление через telegram бота. Без надобности логинится на сервер.
- Возможно управлять через скрипты в домашней директории юзера, запускать от пользователя telegram-gateway.

### Автоматические работы:
- Бекап 23:00 последнего дня месяца
- Автобан по истечению у юзера времени в 0:01 с уведомлением
- Автобан по трафику запускается каждый час (лимит общий, без индивидуальной настройки - 3тб, переменная хранится в variables.lib.sh, можно поставить любое удобное значение)
- Уведомление о трафике юзеров и сервера за месяц со сбросом трафика каждого первого числа и о количестве оставшихся дней у юзеров в 1:01
- Обновление Xray каждое первое число месяца в 2:01 с уведомлением
- Обновления безопасности системы каждое первое число месяца в 3:01 (с возможной автоматической перезагрузкой по надобности) с уведомлением
